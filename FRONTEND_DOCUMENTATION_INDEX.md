## ✅ Pre-Development Checklist

Before you start coding, ensure:

- [ ] Node.js v14+ installed
- [ ] npm v6+ installed
- [ ] Project cloned from Git
- [ ] Dependencies installed: `npm install`
- [ ] `.env.local` file created with `REACT_APP_API_URL`
- [ ] Backend running on port 5000
- [ ] Frontend starts without errors: `npm start`
- [ ] Read FRONTEND_DEVELOPER_HANDBOOK.md
- [ ] Bookmarked FRONTEND_DEV_CHEATSHEET.md
- [ ] Installed React DevTools extension
- [ ] Have a code editor with React/JS support

## 💡 Pro Tips

1. **Keep CHEAT SHEET bookmarked** - You'll use it constantly
2. **Read actual code** - Real examples teach best
3. **Use browser DevTools** - F12 to inspect & debug
4. **Ask for code review** - Learn from senior developers
5. **Write comments** - JSDoc helps future you
6. **Test on mobile** - Use responsive test mode
7. **Check Console** - Red errors need fixing
8. **Use consistent style** - Follow existing patterns
9. **Commit frequently** - Small commits are easier to review
10. **Read error messages** - They tell you what's wrong

## ❓ Still Have Questions?

### Check in This Order:
1. **Search in docs** - Use Ctrl+F (Cmd+F on Mac)
2. **Look at existing code** - Real examples in src/
3. **Check console** - F12 → Console for errors
4. **Ask team** - Slack or in-person
5. **Google it** - Stack Overflow + React docs

### Good Questions to Ask:
- "How should I structure this component?"
- "Can you review my code?"
- "What's the pattern for X?"
- "I'm getting this error, help?"

### Bad Questions:
- "How do I code?" (Read the handbook!)
- "Where does this go?" (Folder decision tree!)
- "How do I import?" (Quick reference!)
